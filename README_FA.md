# پروژه نهان (Project Nahan)

### قدرتمندترین دروازه بدون سرور روی Cloudflare Workers

**نهان** (به معنای *پنهان/مخفی*) یک پروکسی معکوس امن، سبک و قابل سفارشی‌سازی است که به طور کامل روی Edge اجرا می‌شود. این پروژه Worker کلودفلر شما را به یک دروازه قدرتمند و مبهم با پشتیبانی از پروتکل‌های **VLESS** و **Trojan** تبدیل می‌کند که از طریق یک داشبورد زیبا و خودکفا مدیریت می‌شود.

## 🌟 چرا نهان؟

نهان فقط یک اسکریپت پروکسی نیست — یک راه‌حل مدیریت کامل است که برای **مخفی‌کاری**، **سرعت** و **سادگی** طراحی شده.

- 🛡️ **پنهان در دید عموم:** درخواست‌های غیرمجاز به طور خودکار به سایت‌های معتبر (مثل `ubuntu.com` یا `docker.com`) هدایت می‌شوند.
- ⚡ **بدون هزینه سرور:** کاملاً روی پلن رایگان Cloudflare اجرا می‌شود.
- 🎨 **داشبورد مدرن:** رابط کاربری واکنش‌گرا با پشتیبانی از حالت تاریک/روشن و دو زبانه (انگلیسی/فارسی).
- 🤖 **ربات تلگرام:** مدیریت دروازه، بررسی مصرف و دریافت هشدارهای ورود.
- 📡 **چند کاربر و چند IP:** لینک اشتراک اختصاصی + ترکیب با لیست IP پاک.
- 💾 **ذخیره‌سازی D1 SQLite:** تنظیمات در دیتابیس Cloudflare D1 ذخیره می‌شوند.

## 🚀 گزینه‌های نصب سریع

روش مورد نظر خود برای استقرار را انتخاب کنید:

۱. **🌐 نصب‌کننده تحت وب (رابط گرافیکی و آسان):**
   - اجرای نصب‌کننده محلی:
     ```bash
     npm run installer:web
     ```
     سپس آدرس `http://localhost:3000` را در مرورگر باز کنید تا از طریق رابط گرافیکی با توکن کلودفلر، دیتابیس D1 ساخته شده و ورکر با ۱ کلیک مستقر شود.

۲. **💻 ویزارد ترمینال Wrangler CLI (خودکار):**
   - اجرای نصب‌کننده تعاملی خط فرمان:
     ```bash
     npm run install:wrangler
     # یا: ./setup.sh
     ```
     این اسکریپت پیش‌نیازها را بررسی کرده، لاگین کلودفلر را تایید می‌کند، دیتابیس D1 را می‌سازد، فایل `wrangler.toml` را تکمیل کرده و ورکر را مستقیماً روی لبه کلودفلر مستقر می‌نماید.

۳. **🤖 ربات تلگرام نصب:** [@itsyebekhebot](https://t.me/itsyebekhebot)

۴. **📋 پیست دستی در داشبورد:** کپی کردن کد کامپایل‌شده `_worker.js` (تولید شده با `npm run build`) در ادیتور آنلاین کلودفلر.

## 📂 ساختار ماژولار پروژه (`src/`)

کدهای پروژه از حالت یکپارچه و شلوغ به ماژول‌های تمیز و استاندارد ES در پوشه `src/` تفکیک شده‌اند:

```
├── src/
│   ├── index.js              # نقطه ورودی اصلی ورکر (fetch و کران جاب scheduled)
│   ├── core/                 # هسته اصلی (ثوابت، وضعیت، ابزارها، دیتابیس D1، احراز هویت و تنظیمات)
│   ├── protocols/            # پروتکل‌ها (سوکت‌های دودویی، تلگرام وب‌سوکت، تروجان و VLESS)
│   ├── relays/               # سیستم رله‌های خودترمیم، پروب رله‌های قطع و قرنطینه دامنه‌های هوش مصنوعی
│   ├── api/                  # رابط‌های کاربری (کاربران، لاگ‌ها، آمارها، سینک، کلیدها، آپدیت و بات تلگرام)
│   ├── converters/           # تولید سابسکریپشن (Clash، Sing-box، V2Ray، تفکیک بر اساس موقعیت مکانی و فرگمنت)
│   └── templates/            # الگوهای پیش‌فرض و فایل‌های تنظیمات
├── installer/
│   ├── cli.js                # نصب‌کننده تعاملی خط فرمان بر پایه Wrangler
│   └── web/index.html        # نصب‌کننده مدرن تحت وب و دوزبانه (فارسی و انگلیسی)
├── scripts/
│   ├── build.js              # کامپایلر بومی و فوق‌العاده سریع با زمان کمتر از ۲۰ میلی‌ثانیه
│   └── worker_converter.py   # اسکریپت انکود و دیکود ورکر
├── server.js                 # سرور محلی ارائه‌دهنده نصب‌کننده تحت وب و پروکسی کلودفلر (پورت ۳۰۰۰)
├── wrangler.toml             # فایل پیکربندی مدرن Wrangler
└── _worker.js                # نسخه تک‌فایلی و باندل‌شده برای استقرار بدون ابزار
```

## 🚀 راهنمای نصب گام‌به‌گام

### گام ۱: ساخت دیتابیس D1

1. وارد [داشبورد Cloudflare](https://dash.cloudflare.com/) شوید.
2. به **Storage and databases** → **D1 SQLite Database** بروید.
3. **Create database** را بزنید و نامی انتخاب کنید (مثلاً `iot_db`).

### گام ۲: استقرار Worker

1. به **Workers & Pages** → **Create application** → **Create Worker** بروید.
2. نامی بگذارید (مثلاً `nahan-core`) و Deploy کنید.
3. **Edit code** را باز کنید، کد placeholder را پاک کنید و محتوای کامل [`_worker.js`](https://github.com/itsyebekhe/nahan/blob/main/_worker.js) را پیست کنید.
4. **Save and Deploy** بزنید.

### گام ۳: اتصال دیتابیس D1

1. Worker → **Settings** → **Bindings** → **Add binding**
2. نوع: **D1 database**
3. Variable name: **`IOT_DB`** (باید دقیق همین باشد)
4. دیتابیس را انتخاب کنید → Save → Deploy

### گام ۴: ورود به داشبورد

```
https://<آدرس-ورکر-شما>/sync/dash
```

> مراجعه به `/` یا `/sync` بدون `/dash` عمداً صفحه استتار نشان می‌دهد.

### گام ۵: پیکربندی اولیه

1. با کلید پیش‌فرض `admin` وارد شوید.
2. فوراً به تب **System** بروید و:
   - **Master Key** را تغییر دهید
   - **API Route** را به یک مسیر مخفی تغییر دهید (آدرس جدید را بوکمارک کنید!)
   - **Device UUID** را تنظیم یا خالی بگذارید
3. **Update Config** را بزنید.

## 🔩 تنظیمات پیشرفته

### مولتی‌پلکسر IP پاک

در تب **Advanced** لیست IP پاک را وارد کنید (یک IP در هر خط یا فرمت `IP#Name`). اشتراک برای هر IP یک کانفیگ جداگانه می‌سازد.

**ابزارهای پیشنهادی Clean IP:**
- GitHub: [senpaiscanner](https://github.com/senpaiscanner)
- تلگرام: [@itsZetaBot](https://t.me/itsZetaBot)

### Relay IP

ربات پیشنهادی: [@nahanproxyipbot](https://t.me/nahanproxyipbot)

### پنل‌های لینک‌شده (Other Nodes)

اتصال پنل‌های نهان دیگر با **URL + API Key** برای مدیریت متمرکز و انتشار بروزرسانی.  
(فیلدهای قدیمی `slaveNodes` / Cascade به‌طور خودکار به `linkedPanels` مهاجرت می‌شوند.)

### پروفایل چند کاربره

فرمت (یک خط برای هر کاربر):

```
<uuid>:نام‌کاربری
```

دسترسی: `https://<ورکر>/sync/sub?sub=نام‌کاربری`

### ربات تلگرام

1. ربات را از [@BotFather](https://t.me/botfather) بسازید
2. Chat ID را از [@userinfobot](https://t.me/userinfobot) بگیرید
3. در تب Advanced وارد کنید و ذخیره کنید

دستورات: `/status` و `/pause` (Kill Switch)

### کلید قطع اضطراری (Kill Switch)

از تب Advanced یا دستور `/pause` در تلگرام برای توقف فوری ترافیک پروکسی استفاده کنید.

## 💾 ذخیره تغییرات

پس از هر تغییر در تب‌های **System** یا **Advanced**:

1. روی **Update Config** کلیک کنید.
2. منتظر «Syncing...» بمانید تا صفحه بارگذاری مجدد شود.

اگر API Route را تغییر دادید، صفحه به مسیر جدید هدایت می‌شود — آن را بوکمارک کنید.

## ❓ سوالات متداول و رفع اشکال

**پیام `⚠️ IOT_DB namespace missing!`**  
→ Binding دیتابیس D1 وجود ندارد یا نام متغیر دقیقاً `IOT_DB` نیست. در Settings → Bindings اصلاح و Redeploy کنید.

**آدرس اصلی سایت Ubuntu/Docker نشان می‌دهد**  
→ رفتار عمدی است. همیشه از `/sync/dash` (یا مسیر سفارشی + `/dash`) استفاده کنید.

**Master Key یا API Route را فراموش کرده‌ام**  
→ مقادیر را از D1 Console (کلید `sys_config`) بازیابی کنید.

**محدودیت پلن رایگان**  
→ ۱۰۰٬۰۰۰ درخواست در روز. از بخش Cloudflare Analytics در Advanced مصرف را مانیتور کنید.
