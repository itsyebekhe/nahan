Wrangler CLI Automated Installer

Prefer deploying from your local terminal using the official Cloudflare Wrangler tool? Follow these simple automated commands:

Option A: Run Interactive CLI Installer 
npm run install:wrangler

Guides you step-by-step in terminal, creates D1 database automatically, updates wrangler.toml, and deploys.

Option B: Standard Wrangler Commands 
# 1. Create D1 SQLite database
npx wrangler d1 create nahan-db

# 2. Deploy directly to Cloudflare
npx wrangler deploy
Generated wrangler.toml Configuration

Modular Architecture Overview

The 11,000-line monolithic _worker.js has been thoroughly refactored into high-performance ES modules located in src/:

src/core/
  • • constants.js
  • • state.js (Memory Caches)
  • • utils.js (Timeouts & Helpers)
  • • d1.js (SQLite DB Engine)
  • • auth.js (Keys & Rate Limit)
  • • config.js (Sync & Failover)
src/protocols/
  • • stream.js (Sockets & Tunnels)
  • • trojan.js (Auth & UUID Map)
src/relays/
  • • health.js (Relay Probing)
  • • Graveyard Auto-Recovery
  • • AI SNI Domain Quarantine
src/api/
  • • auth.js & keys.js
  • • users.js (Quota Tracker)
  • • logs.js & stats.js
  • • sync.js (Linked Nodes)
  • • telegram.js (Bot Webhook)
  • • update.js (Edge Deploy)
src/converters/
  • • geo.js (IP Flags & Geolocation)
  • • fragment.js (TLS Masking)
  • • upstream.js (Detour Chains)
  • • sub.js (Clash / Singbox / V2Ray)
src/index.js
  • • fetch() Entry Point Router
  • • scheduled() Background Cron
  • • Wrangler main entry
